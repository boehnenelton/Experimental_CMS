## Audit Scope & Method

**Audited (current live codebase):** `EXPCMS.py` (v3.7.0), `EXPCMS_Builder.py` (v3.0.5), all of `Lib_PY/ExpCMS/`, the `Lib_PY/Core/` + `Lib_PY/HTML/` modules actually reachable from the two entry points, all `templates/`, `Components/`, `HTML_Skeletons/`, and the **live** workspace data under `Data/workspace/db_global` and `db_content`.

**Excluded per instruction (historical/archived, not audited as current code):**
- `CHANGELOG.md` / `cleanup-log.md` / `BUGFIX_*.md` / `security-notes.md` — treated as historical logs only (used solely to cross-check claims against current code).
- `Chunked_CLI_Doc_Chunker_v1.104db.bejson.txt` — an archived chunk artifact. It contains an **older** Doc_Chunker (v2.2.0 with legacy `import lib_bejson_core`); not audited as live code.
- `docs/usage-guide.md` and `README.md` claims were checked *against* the code (findings in §7).

Trace base: `EXPCMS.py` → `lib_bejson_ExpCMS_cms_mfdb` / `_widgets` / `_chunker_wrapper` → `_mfdb_chunker_v6` → `Lib_PY/Core` (bejson_core, mfdb_core, path_guard). All imports resolve in the current layout (Core/HTML/ExpCMS families on `sys.path`). No dangling CMS import.

## CRITICAL

### C1. Zip-Slip in Standalone App import — `/apps` route (`EXPCMS.py`)
`z.extractall(app_dir)` unguarded on an uploaded app zip — the same vulnerability class fixed in pkg24's chunker (LIB-CH-H2), missed on this route. **Fixed pkg25**: routes through `safe_extract_zip()` + a member-count/size guard.

### C2. Stored XSS via HTML Import
`import_html_as_page()` did no sanitization at all despite README/usage-guide claiming BeautifulSoup stripping; `html_body` renders with `| safe` on every built page. **Fixed pkg25**: `_sanitize_imported_html()` added.

## HIGH

### H1. Admin app exposed to the network with debugger enabled
`app.run(host='0.0.0.0', debug=True)`, zero authentication anywhere. **Fixed pkg25**: defaults to `127.0.0.1`/debug off, env-configurable.

### H2. MediaAsset schema drift breaks all media uploads on older installs
No entity-schema migration mechanism existed. **Fixed pkg25**: `_reconcile_global_schema()` added, run on every mount.

### H3. Standalone App category select doubly broken
Form/route field-name mismatch (`category` vs `category_fk`) plus wrong dropdown dict keys. **Fixed pkg25**.

### H4. Featured-image dropdown in the page editor always empty
Checked `content_type` instead of `mime_type`. **Fixed pkg25** (and a second instance of the same bug class found and fixed in pkg26 — `original_filename` vs `original_name`).

### H5. Live data integrity violation: orphan page with `category_fk=""`
**Fixed pkg25**: reassigned to `uncategorized`.

### H6. Built-site iframe path for Standalone App pages wrong
Self-embedding loop. **Fixed pkg25**: corrected to `../../apps/<app_uuid>/<entry_file>`.
