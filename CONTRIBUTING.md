# Contributing

## Bug Reports

Include: the route or CLI command you ran, the exact input (form fields,
file, or CLI args), and the full traceback if one appeared. If the bug
involves a built static page, include the page's category/feed type and,
if possible, the generated HTML from `Processing/www/`.

## Feature Requests

Describe the workflow you're trying to support and which existing route
or page it's closest to. New widgets should follow the portability
contract in `AGENTS.md` (no external CDN dependencies, CSS scoped under a
unique per-instance wrapper class).

## Noncommercial Contribution Terms
